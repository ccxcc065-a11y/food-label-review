# 公开版本验证范围

日期：2026-11-14。此记录针对公开分发与合成演示，不是食品合规业务验收。

| 验证 | 结果与可复现入口 |
|---|---|
| Python 离线测试 | 30 项；`python -m unittest discover -s tests -p 'test_*.py' -v` |
| Node 报告测试 | 12 项；`node --test tests/test_report.js` |
| HTML/CSS 资源和角色文件 | 分发测试检查引用文件存在；HTTP 脚本读取首页、管理页、CSS、JS 和样例 |
| 七行营养数据 | 合成预置观察的项目、值、单位、NRV 与基准逐项断言；不是 live OCR |
| 无语料弃权 | 没有标准正文时不产生 pass；91 项账本不显示通过 |
| 演示禁用模型 | HTTP 脚本故意带 AI 开关，服务端仍返回 skipped；演示不花模型额度 |
| 实际保存与下载 | HTML 检查通过；重复 GET 字节相同，SHA-256 与 contentHash 一致 |
| 浏览器交互 | 实际点击合成样例、字段校对、脂肪定位、下载 HTML、重新审核；截图在 images/ |
| 本机 PDF | 可用条件与实际生成单独记录；不把页数或生成成功当逐页版式验收 |

当前 CI 增加干净检出 HTTP 路径，避免离线测试全绿但网页缺资源。运行时长与本机环境相关，不设一个脆弱的墙钟阈值来判正确性。
